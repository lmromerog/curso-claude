Resttek API (1.0.0)

Download OpenAPI specification:

API REST de la plataforma de gestión de restaurantes Resttek.

Autenticación

Los endpoints protegidos requieren una cabecera Authorization: Bearer <token>. El token (JWT, válido 8 horas) se obtiene en POST /auth/login o POST /auth/register y contiene {id, role, restaurantId}.

Roles

admin, manager, camarero, cocinero y cliente. Los clientes son registros de empleados con rol cliente.

Errores

Los errores de dominio responden { "error": "<NombreDelError>", "message": "<detalle>" } (400 por defecto, 401 para credenciales inválidas, 404 para recursos inexistentes). Los fallos de autenticación/autorización y los endpoints de pedidos responden solo { "error": "<detalle>" }.
